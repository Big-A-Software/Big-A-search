The idea

An independent
search project.

Lux is a free and open-source search engine developed by Big-A. It began as a Google-powered search page and is now being rebuilt around its own crawler, index, search interface, and API.

01 / DISCOVER

Crawl the web

Lux gathers information from a selected and expanding collection of websites.

02 / ORGANIZE

Build the index

Page information becomes structured searchable data rather than a pile of disconnected documents.

03 / FIND

Return results

Queries move through the Lux index and matching pages become search results.

Under the surface

What happens
behind a search.

Lux crawls approved websites, stores searchable information from their pages, and uses that index to answer searches. The network below is a visual illustration of those parts working together.

The collection
13,800+

websites crawled.

Lux is still a young search engine, so its index covers a selected collection of websites rather than the entire web. Each added website expands what Lux can search.
