🎉 Big-A Search Is Back Online!

This marks a major change for Big-A Search.

The previous version of Big-A Search used Google Programmable Search Engine.

Big-A is now developing and operating its own search system. Big-A Search maintains its own list of websites, crawls selected pages, builds a search index, and searches that index using Big-A's own code.

This gives Big-A Search much greater control over what websites are included and how the search engine develops.

Big-A Search is also free and open-source software.

About Big-A Search

Big-A Search is a free and open-source search engine developed by Big-A.

Big-A Search is one of the projects developed by Big-A.

Rather than attempting to search every website on the Internet, Big-A Search focuses on a selected and growing collection of websites.

Its source code is designed to remain straightforward and understandable so people can examine, modify, learn from, and contribute to the project.

Add a Website to Big-A Search

Big-A Search's website list is maintained publicly on GitHub.

Websites are stored in:

data/sites.json

Add the site's main domain name. Do not add an individual page.

Example:

[
  "softpedia.com",
  "amazon.com",
  "hp.com",
  "example.com"
]

Each domain must be inside quotation marks. Put a comma after every entry except the final entry.

Big-A may crawl pages belonging to the listed domain and its subdomains according to Big-A's crawler rules.

Submit the change through GitHub so it can be reviewed before becoming part of Big-A Search.
