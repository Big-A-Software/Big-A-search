# Big-A Search

Big-A Search is a free and open-source search engine developed by Big-A.

Big-A Search searches a hand-picked collection of websites. Rather than
attempting to search the entire web, Big-A Search is designed around a
growing collection of websites selected for inclusion in its search index.

Big-A Search is one of the projects developed by Big-A.

## Project Status

Big-A Search is currently under development.

The current version uses Google Programmable Search Engine. Big-A Search
is being developed into an independent search engine with its own crawler,
index, and search system.

## Goals

Big-A Search is being designed to:

- Crawl websites selected for inclusion in Big-A Search
- Build and maintain its own searchable index
- Search only the websites included in Big-A Search
- Allow new websites to be added easily
- Provide a simple and easy-to-use search page
- Keep the source code easy to read and understand
- Remain free and open-source software

Big-A Search is not intended to crawl the entire Internet or compete with
large general-purpose search engines. Its purpose is to provide a useful
search engine for a selected and growing collection of websites.

## How Big-A Search Works

Big-A Search consists of four main parts:

1. **Crawler** — visits selected websites and reads their pages.
2. **Index** — stores information about pages discovered by the crawler.
3. **Search Engine** — finds and ranks pages that match a search.
4. **Website** — provides the Big-A Search interface and displays results.

Big-A Search is being developed primarily with JavaScript, HTML, and CSS.

Contributions, improvements, forks, and experimentation are welcome.

be able to read the source code, understand it, modify it, and learn from it.
