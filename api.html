Big-A Search API

Search Big-A's own web index from another website or program. No Big-A account is required. A Big-A API key is required for searches.

Generate an API key

Click once and save the key somewhere safe. Big-A does not store a copy of the generated key.

No key generated yet.

Search endpoint

GET /api/search?q=windows

Send your key using either of these request headers:

X-Big-A-Key: BA1.your-key-here

Authorization: Bearer BA1.your-key-here

Try it

Results will appear here.

Example response

{
  "engine": "Big-A Search",
  "query": "windows",
  "count": 2,
  "results": [
    {
      "title": "Example result",
      "url": "https://example.com/",
      "description": "Page description..."
    }
  ]
}

Limits

The optional limit parameter can request 1 to 50 results. Big-A may add rate limits and additional API features as the service develops.
