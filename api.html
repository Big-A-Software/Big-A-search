Big-A Search API

Use Big-A's search technology from your own website or program. Big-A Search itself is public: no account and no API key are required simply to search. API keys are optional integration identifiers for developers embedding or using Big-A technology.

Generate an integration API key

Generate a Big-A key to identify your website or application when it uses Big-A technology. The key is not required to access ordinary Big-A search.

No key generated yet.

Public search endpoint

GET /api/search?q=windows

No key is required. A developer using an integration key may optionally send it as:

X-Big-A-Key: BA1.your-key-here

Authorization: Bearer BA1.your-key-here

Try it

Results will appear here.

Use it on a website

fetch('/api/search?q=' + encodeURIComponent('windows'), {
  headers: {
    'X-Big-A-Key': 'BA1.your-key-here'
  }
}).then(r => r.json()).then(console.log);

The header identifies the integration. Removing the header does not disable public searching.

Limits

The optional limit parameter requests 1 to 50 results. Big-A may add integration statistics, custom Search Engine IDs, and reasonable rate controls as the API develops.
